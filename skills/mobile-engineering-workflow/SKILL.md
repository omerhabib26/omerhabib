# Mobile Engineering Workflow

Inspect the task and repository instructions. Preserve unrelated work. Use the relevant references below at each stage; skip stages only with an explicit reason.

1. Plan acceptance criteria with references/plan-mobile-feature.md.
2. Define state and API contracts with references/design-mobile-contracts.md.
3. Implement the smallest coherent change. Treat generated code as a proposal.
4. Verify behavior with references/verify-mobile-delivery.md.
5. Investigate failures with references/debug-with-telemetry.md.
6. Review the final diff with references/review-mobile-change.md.
7. Prepare commits, PR, CI evidence, and release using references/ship-with-github-actions.md.

Return the implemented behavior, verified test results, artifacts or links, and material limitations. Distinguish planned work from demonstrated results.
